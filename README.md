# FM estudio

Web de FM estudio: diseño y desarrollo de sitios web, landing pages y tiendas online para negocios.

Una pieza 3D procedural acompaña el scroll: empieza como boceto de alambre y termina pulida al llegar al contacto.

## Tecnología

- [Three.js](https://threejs.org) para la pieza 3D (geometría y materiales generados por código, sin modelos externos).
- [GSAP](https://gsap.com) y ScrollTrigger para las animaciones ligadas al scroll.
- [Lenis](https://lenis.darkroom.engineering) para el scroll suave.
- Respeta `prefers-reduced-motion`, navegación por teclado y contraste AA.

## Ver en local

```powershell
python -m http.server 5173
```

Abrí http://localhost:5173
